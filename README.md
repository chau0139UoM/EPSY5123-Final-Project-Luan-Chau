In this project, I designed an end-to-end R workflow using a dataset derived from a larger intervention study investigating the effects of different types of chatbot-based refutations on belief change about AI among educational stakeholders.

The folder structure is organized as follows:

- Code: Contains the main R Markdown file used for data processing, analysis, visualization, and reporting.
- Data: Contains the dataset used in the project.
- Documentation: Includes a justification explaining how this secondary analysis contributes new insights while avoiding overlap with previous projects.
- Output: Contains the rendered HTML file generated from the R Markdown workflow.
- 
The main purpose of this project is to investigate whether belief change occurred consistently across different AI misconceptions following chatbot-based refutation interventions.
